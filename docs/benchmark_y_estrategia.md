# Benchmark y estrategia para una app de repostería (abril 2026)

## 1) Benchmarking rápido de productos actuales

| App / plataforma | Valor principal | Fortalezas | Huecos detectados |
|---|---|---|---|
| Paprika Recipe Manager | Gestión de recetas, escala y conversión | Muy maduro en guardar/organizar recetas y convertir/ajustar cantidades | No es específico de repostería comercial (costeo por lote + márgenes de negocio). |
| CakeCost (iOS) | Cálculo de costos/precio para reposteras | Enfoque claro en pricing de pasteles | Feedback público sugiere mejoras en listas maestras y reutilización de recetas. |
| BatterProfit | Flujo de costeo completo (ingredientes + mano de obra + extras) | Muy claro para estimar cotizaciones rápidas | Menos énfasis en recetario formativo y asistente inteligente continuo. |
| CakeFlow Planner | Costeo + recalculado de recetas + operación de negocio | Visión todo-en-uno orientada a reposteras que venden | Espacio para diferenciarse en UX educativa y chat experto contextual. |

### Conclusión de benchmark
Hay mercado validado para **costeo + recetario + flujo de negocio**, pero sigue abierta una oportunidad en una experiencia unificada para LATAM que combine:
1. Recetario clásico curado.
2. Costeo multicurrency fácil.
3. Conversión universal de medidas.
4. Chat experto especializado en repostería.

## 2) Propuesta de producto (tu app)

### Módulos núcleo (MVP)
1. **Recetario clásico** con recetas base validadas y escalables.
2. **Tabla de costos inteligente**: costo por receta/lote/unidad + margen sugerido.
3. **Conversor de medidas internacional** (gramos/oz/tazas/ml y derivados).
4. **Chat repostero** para dudas técnicas (textura, horneado, sustituciones, seguridad alimentaria).

## 3) Diferenciadores sugeridos
- **Modo negocio**: precio sugerido por país y moneda.
- **Modo aprendizaje**: explicación de "por qué" (ej. por qué se corta una ganache).
- **Plantillas rápidas**: cotización por tipo de pedido (pastel boda, cupcakes, galletas decoradas).
- **Historial de lotes**: comparar costos históricos y margen real.

## 4) Paso a paso para monetizar

1. **Lanzamiento freemium**
   - Gratis: recetario base + conversiones + 20 cálculos/mes.
   - Pro: cálculos ilimitados, reportes, exportación PDF, historial y chat avanzado.

2. **Pricing recomendado inicial**
   - Mensual: USD 7–12.
   - Anual: 20–30% descuento.
   - Plan Studio (micro negocio): USD 19–29 con 2–5 colaboradoras.

3. **Upsells de alto valor**
   - Pack recetas premium (temporadas/países).
   - Calculadora avanzada (mermas, energía, empaques, comisiones de marketplace).
   - Mini-CRM de pedidos.

4. **Canales de adquisición**
   - TikTok/Instagram con contenido "precio tu pastel conmigo".
   - Embudo con lead magnet (plantilla gratuita de costeo).
   - Comunidad WhatsApp/Telegram para retención.

5. **Métricas críticas**
   - Activación D1: usuario crea 1 receta + 1 costeo.
   - Retención W4: vuelve a calcular al menos 3 veces.
   - Conversión a pago: desde primer "momento wow" (ahorro o ganancia real).

## 5) Riesgos y mitigación
- **Riesgo**: datos de costos incompletos por país.  
  **Mitigación**: permitir precios manuales + autoguardado por ingrediente.
- **Riesgo**: chat con respuestas inseguras.  
  **Mitigación**: reglas de seguridad alimentaria + respuestas con disclaimers cuando aplique.
- **Riesgo**: churn por falta de hábito.  
  **Mitigación**: recordatorios semanales de margen/ganancia.
